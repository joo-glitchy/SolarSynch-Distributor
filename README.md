# SolarSynch-Distributor (Netlify Deployment Test)

## Overview

This project was a small test of Netlify using a website created by my dad with the help of AI.

The goal was to explore how Netlify can be used to deploy and host a website, making it accessible online without requiring a traditional web server setup.

## Objectives

- Test the deployment of an AI-assisted website using Netlify.
- Explore the process of publishing a website online.
- Understand the basics of web hosting and deployment.
- Experiment with Netlify's deployment workflow.

## Technologies and Tools

- **Netlify** — Website hosting and deployment platform.
- **AI-assisted website creation** — The website was created by my dad with the help of AI.

## What I Learned

This experiment provided an opportunity to explore Netlify and gain practical experience with the website deployment process.

It also helped me better understand how AI-assisted website creation can be combined with modern hosting platforms to publish websites online.
